Basal Router — provider keys

Keys are saved to providers.json (chmod 600, outside the repo). The panel listens on 127.0.0.1 only. The Test button sends a one-token request to the provider's probe model. The registry contains free and local models only.

add a provider (OpenAI-compatible)

Creates a new entry in providers.json; wire models to it in models.json with the "provider" field and "runner": "direct".

Security: keys are masked in the panel API and never logged; saves are protected by the x-panel header (against CSRF) and a Host check (against DNS rebinding). Local only — do not expose this panel beyond 127.0.0.1.
