Basal Router — control panel

One model to rule them all. Keys are stored in providers.json (chmod 600, outside the repo); the panel listens on 127.0.0.1 only and never logs keys. Settings apply from the next request — no restart. The registry holds max 20 options (an ollama-mode limit).

model discovery

The registry self-updates from models.dev, the live opencode list and the OpenRouter free catalog; cards for new models are written by a free model. Cron refreshes every 6 hours.

add a provider (OpenAI-compatible)

Creates an entry in providers.json. Then save its key, open its catalog and import models into the registry (imported models run via your key, runner "direct").

Security: keys are masked in the panel API and never logged; writes are protected by the x-panel header (CSRF) and a Host check (DNS rebinding). Local only — do not expose this panel beyond 127.0.0.1. Removing a provider is blocked while registry models use it; removing a model is blocked for the default model.
